# Qollab Logo

![Qollab logo](public/brand/qollab-lockup.svg)

## Brand idea

A ring and a pointer that together draw a **Q**. The ring is the room: a table
people sit around, with nobody at the head. The pointer is a person arriving:
the live cursor everyone sees when someone joins.

Tagline: **Same room. Same page.**

The letters are built from the same ring and a straight stem. They are drawn,
not typed, so never set the name in a font to stand in for the logo. In running
text write "Qollab", capital Q.

## Files

| File in `public/brand/`     | Use                                              |
| --------------------------- | ------------------------------------------------ |
| `qollab-lockup.svg`         | White and soft grey grounds                      |
| `qollab-lockup-reverse.svg` | Ink grounds                                      |
| `qollab-lockup-white.svg`   | Cobalt, photos and other colours                 |
| `qollab-lockup-ink.svg`     | Single-ink print                                 |
| `qollab-mark*.svg`          | The mark alone, in the same four versions        |
| `qollab-app-icon.svg`       | Source for `src/app/icon.png` and `apple-icon.png` |

In the app use `QollabBrandLogo` (`variant="lockup"` or `"mark"`). It draws the
SVG as a background, at 136px wide, 116px up to 760px, and 32px for the mark.

## Colours

- Ring and letters: ink `#0E1024`. Pointer: cobalt `#2B4BFF`.
- On ink: white ring and letters, light cobalt pointer `#8098FF`.
- App icon: white ring and sun pointer `#FFC233` on cobalt.

## Usage

- Lockup from 88px wide; below that use the mark, down to 16px.
- Clear space on every side is half the height of the mark.
- Only the pointer may change colour, and only in presence or campaign work.
- Do not stretch, rotate, outline or shadow the logo, move the pointer, or close
  the gap between pointer and ring.

## Accessibility

When the logo is the only content of a link, name the link, for example "All
study rooms". In documents use the alternative text "Qollab".
