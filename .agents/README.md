# Qollab engineering and product documentation

Qollab is a room-based collaborative study workspace with notes, PDFs,
whiteboards, breakout Q&A, and AI study materials. The root [README](../README.md)
and [architecture](./ARCHITECTURE.md) describe current behavior. Older documents
may use Canvas, BoardPrep, or MyBoardPrep; those are historical product names.

## Start here

- [Environment](./ENVIRONMENT.md): actual setup and executable commands.
- [Architecture](./ARCHITECTURE.md): implemented boundaries and data flow.
- [Testing](./TESTING.md): local checks, hosted verifiers, and evidence limits.
- [Design](./DESIGN.md): canonical Astryx, typography, and interaction rules.
- [Style guide](./STYLEGUIDE.md): current coding conventions.
- [API](./API.md), [database](./DATABASE.md), and [security](./SECURITY.md): domain details.
- [Decisions](./DECISIONS.md): historical decisions with supersession notes.
- [Roadmap](./ROADMAP.md) and [PRD](./PRD.md): direction and requirements, not a
  guarantee that every listed feature or performance target is implemented.

The repository uses an SVG/Yjs whiteboard, not Excalidraw; React/Yjs state,
not Zustand. Case discussions, institutional roles, and measured latency/learning
outcomes are future requirements, not current capabilities.
